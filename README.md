# WhoisGhost 👻
Ferramenta interativa de consulta WHOIS desenvolvida em Python 3.

## 🚀 Funcionalidades
- Consulta automatizada (IANA -> Servidor específico).
- Interface colorida e interativa.
- Limpeza automática de URLs (remove http/https).
- **Salvamento automático** dos resultados em `.txt`.

## 🛠️ Como usar
1. Clone o repositório:
   `git clone`
2. Entre na pasta:
   `cd WhoisGhost`
3. Execute:
   `python3 WhoisGhost.py`
